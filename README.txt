WUWA COMMUNITY Discord Server紹介サイト

■ 最初に変更する場所
script.js の CONFIG を変更してください。
INVITE_URL = 実際のDiscord招待URL
SERVER_ID = DiscordサーバーID（人数表示を使う場合）

■ Discord人数表示
Discord側で Server Widget を有効にし、SERVER_IDを設定してください。

■ 管理者紹介
index.html の STAFF セクションの名前・役職を変更してください。

■ JavaScriptのインストール
不要です。ブラウザだけで動作します。

■ メイン画像
assets/hero.jpg にユーザー提供画像を使用しています。
